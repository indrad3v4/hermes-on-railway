   handoffs' from 'window was empty' - two situations with very different fixes.
D4 PATH-A (S2:4657, reason string S2:4663) is effectively unreachable in this build: _find_tail_cut_by_tokens
   floors the cut to head_end+1 (S2:4245-4246, S2:4263) and _compress_window only lowers compress_end to a
   bridge_idx that must satisfy bridge_idx > compress_start (S2:4373-4374), so compress_start>=compress_end
   cannot arise from the tail walk. The label it guards is dead code in practice.
